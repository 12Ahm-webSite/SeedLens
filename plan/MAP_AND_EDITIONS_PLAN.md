## 1. نتائج الدراسة المقارنة (Chunkbase & MCSeedMap)

بعد التدقيق الشامل لطريقة عرض الخرائط وتجربة المستخدم في كل من **Chunkbase** و **MCSeedMap**:

| المعيار | Chunkbase | MCSeedMap | SeedLens (رؤيتنا مع الحفاظ على التصميم) |
| :--- | :--- | :--- | :--- |
| **محرك الخريطة** | WebGL / Canvas مع مربعات ألوان 2D | Canvas مع Mantine | Leaflet مكسو بهوية ماينكرافت الداكنة الأصيلة |
| **التحكم بالطبقات (POI)** | شريط أفقي لأيقونات الهياكل بضغطة زر | أزرار تصنيف وقوائم منسدلة | شريط أزرار بكسلية أعلى الخريطة لتبديل الهياكل والمعالم |
| **شريط الإحداثيات (HUD)** | شريط إحداثيات حي والبيوم أسفل الخريطة | إحداثيات حية أعلى الخريطة | شريط إحداثيات أنيق ومدمج بزاوية الخريطة |
| **بطاقات المعاينة (Hover)** | صندوق نصي رمادي جاف وممل | صندوق نصي تقليدي | **بطاقة مدمجة ذكية بصورة حقيقية بحسب الإصدار وأزرار /tp** |
| **تقييم الأماكن** | غير موجود نهائياً (مجرد إحداثيات) | غير موجود نهائياً | **تقييم خوارزمي حصري لجمال الموقع وسهولة البناء** |

> [!IMPORTANT]
> **قاعدة إلزامية:** تصميم SeedLens العام (الألوان، الثيم المظلم، أزرار الحجر والخشب، والخطوط البيكسلية) **ثابت ولا يتم تغييره**. كل الميزات المذكورة تُدمج بسلاسة تامة لتخدم الهوية القائمة وتمنح راحة استثنائية للمستخدم.

## 2. نظام إصدارات 2026 الجديد (Minecraft Game Drops & 26.x)

### أ. لماذا تظهر إصدارات مثل `Java 26.3` و `Bedrock 26.50`؟
* اعتمدت شركة **Mojang** رسمياً نهجاً جديداً لتحديثات ماينكرافت يتمثل في **إسقاطات منتظمة وسريعة (Game Drops)** بدلاً من التحديث السنوي الفردي البطيء (مثل 1.20 أو 1.21).
* بدأت المواقع العالمية وأدوات الاستكشاف باستخدام الترقيم السنوي لعام 2026 (`26.1`, `26.2`, `26.3`) لتتبع هذه الإسقاطات الدورية والتحديثات التجريبية بدقة.

### ب. خطة التطبيق في محرك SeedLens:
1. الاستفادة من معمارية `VersionProfile` المرنة في [`engine/src/version.c`](file:///home/pc/Desktop/SeedLens/engine/src/version.c).
2. إضافة الأسماء البديلة (**Aliases**) مثل:
   * `"26.3"`, `"26.x"`, `"latest"` لترتبط تلقائياً بأحدث بروفايل في المحرك.
   * إبقاء التوافقية الكاملة مع الترقيم التقليدي (`1.21.4`, `1.21.1`, `1.20.6`, `1.18.2`).
3. تحديث قائمة الإصدارات في واجهة المستخدم لتتيح اختيار التحديثات بأسماء واضحة ومفهومة.

## 3. استراتيجية دعم نسخة البيدروك (Bedrock Edition Integration)

### أ. حقيقة التكافؤ التضاريسي والبيومي (Terrain & Biome Parity)
* منذ إصدار **Minecraft 1.18 (Caves & Cliffs II)**، تم توحيد خوارزمية توليد التضاريس والبيومات بالكامل بين نسختي Java و Bedrock.
* **ماذا يعني هذا لمستخدمي البيدروك؟**
  * أي بذرة 64-bit تُعطي **نفس الجبال، نفس البحيرات الدائرية، نفس فوهات الكرز، ونفس الوديان في نفس الإحداثيات بالضبط بين Java و Bedrock**.
  * ميزة SeedLens الاستثنائية لاكتشاف **المواقع الطبيعية وأماكن البناء (Landmarks)** صالحة وتعمل على البيدروك بنسبة **100% بالبلوكة**.

### ب. الفروقات في الهياكل (Structures) والحلول الذكية:
* بعض الهياكل (كالقرى أو معابد الصحراء) قد تختلف مواقعها بين النسختين بسبب اختلاف مولد الأرقام العشوائية في محرك البيدروك.
* **الحل في واجهة SeedLens:**
  * إضافة مفتاح اختيار النسخة أعلى الواجهة:
    `[ ☕ Java Edition | 🪨 Bedrock Edition ]`
  * عند اختيار **Bedrock**:
    1. تفعيل كافة ميزات الـ Landmarks والمناظر الطبيعية والبحيرات مع وسم يوضح أنها **متطابقة 100% مع البيدروك**.
    2. توضيح حالة الهياكل بشفافية احترافية مع عرض الهياكل المرجعية المتطابقة.

## 4. بطاقات التمرير الذكية والمدمجة على الخريطة (Version-Contextual Hover Cards)

بناءً على التوجيه المعتمد، سنلغي النوافذ المعقدة ونتفوق على Chunkbase و MCSeedMap ببطاقات مريحة ومباشرة:

```
+-----------------------------------------------------+
| [ صورة المعلم الواقعية الخاصة بـ 1.21 فقط ]         |
|                                                     |
| 🌸 فوهة أزهار الكرز (Cherry Blossom Caldera)       |
| 📍 X: 1,420 | Y: 112 | Z: -860                      |
| 🏔️ الجمال: 95/100  | 🔨 سهولة البناء: 88/100         |
|                                                     |
| [ 📋 نسخ /tp 1420 112 -860 ]  [ 🔍 تفاصيل المعلم ]   |
+-----------------------------------------------------+
```

### الخصائص الهندسية للبطاقة:
1. **مدمجة ومريحة (Compact & Ergonomic):** تظهر بنعومة عند تمرير الفأرة فوق الدبوس، وتختفي بسلاسة دون تشويش على بقية الخريطة.
2. **صورة واقعية متوافقة حصراً مع الإصدار المختار:**
   * إذا كان الإصدار المختار هو **1.18**، تظهر صورة المعلم في تضاريس 1.18 فقط.
   * إذا كان الإصدار **1.21+**، تظهر المعالم وهياكل الـ Trial Chambers الخاصة بـ 1.21 مباشرة.
   * تجنب التبويبات المتعددة المشتتة داخل الـ Tooltip لضمان سرعة الفهم.
3. **أمر الانتقال المباشر بنقرة واحدة:** زر سريع لنسخ أمر `/tp X Y Z` للاعب مباشرة داخل اللعبة.

## 5. شريط أدوات الخريطة (Map Toolbar & HUD)

* **شريط الطبقات المدمج (Layer Toggles):**
  * أزرار صغيرة ومصقولة بنفس ثيم ماينكرافت أعلى الخريطة لتبديل عرض:
    * `[ 🏰 الهياكل ]`
    * `[ 🌸 المواقع الطبيعية والفوهات ]`
    * `[ 💎 العناقيد الخارقة ]`
* **شريط الإحداثيات الحي (Coordinates HUD):**
  * شريط شفاف أسفل الخريطة يُظهر إحداثيات مؤشر الفأرة `X, Z` لحظياً أثناء التحريك.
